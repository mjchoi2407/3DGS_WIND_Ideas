# R0·R1 구현 상태 동기화

## 현재 상태

- 확인일2026-09-14. 사용자 요청으로 canonical R0/R1에 미반영된 구현·검증 상태를 반영했다. R0/R1 전체 미완료 판정은 유지했다.
- 후속 정확도 진단까지 R1에 반영했다. 고차 적분은 짧은 구간에서 정확도 개선 후보이며, 전체 시간 수렴·독립 Gauss 검산·가속화는 미완료다. [실험 근거](../../experiments/R1_teacher_velocity_reset/timestep_search/cloth_coarse/bend500_accuracy.md).
- R0는 Teacher의 SI/hash/상태 기록 구현과 target package/schema/fixture 전체 완료를 구분했다.
- R1은 FP64 hi/lo GPU 상주 Newmark/Newton/GMRES·독립 검산·국소 기하·중력/굽힘 구현을 반영했다. CPU+HVP 채택 설명은 과거 상태로 수정했다. 1/100·1/300 제한 검증과1/500 미완료 판정, 하이브리드 사용자 종료를 반영했다.
- 최종 공간/시간 수렴·고차 매핑·독립 GS 공통 영역·oracle/transport 및 접촉은 미완료다. 연구 claim/Gate 변경이 없어 master/sketch source는 수정하지 않았다.
- 상세 수치·원본은 experiments 소유 문서를 연결했다. 최초 문서 동기화에서는 재실행하지 않았으며, 아래 후속 진단은 별도 GPU 실험 근거를 반영했다. 외부 fetch는 수행하지 않았다.
- `latexmk -cd -g -xelatex -interaction=nonstopmode -halt-on-error development/r0_contract_and_schema.tex` 및 R1 대응 명령 성공. canonical PDF2개 갱신, master 전달 bundle의 R0/R1 TeX/PDF와 development README5개 항목만 갱신하고 byte 일치/CRC 확인했다. 나머지 ZIP 항목은 보존했다.
- [공통 지침](../../AGENTS.md#정리-요청과-r-문서-동기화)에 정리 요청 시 관련 R 문서까지 동기화하도록 명시했다. [R 문서 안내](../development/README.md)에서 연결한다.
- 기존 dirty 변경은 보존했고 stage·commit·push 없음.

## 1/500 후속 진단 반영

사용자 요청 GPU 재현에서 GMRES720회 한도 실패를 확인하고 dt절반3프레임 검산 통과와 시간 수렴 미완료를 R1에 반영했다. [실험 근거](../../experiments/R1_teacher_velocity_reset/timestep_search/cloth_coarse/bend500_failure_diagnosis.md). R1 XeLaTeX 재빌드 성공·non-empty PDF 및 전달bundle 대응2항목 일치/CRC 확인. R0/Gate/기본dt는 변경하지 않았다.

## 학습 정확도 후속 진단 반영

동일2초 seed의 시간 세분화와 기존 고차 Gauss 후보 대조를 R1에 반영했다. 한 프레임의 순간 속도 질량·시간 RMS와 매우 짧은 구간의 끝 속도 차이를 구분하며, 정밀 기준 자체의 차이도 기록했다. 시각적 유사성이나 내부 반복 수렴만으로 학습 적격성을 판정하지 않는다. 수치·조건·비용과 미완료 검사는 [정확도 보고서](../../experiments/R1_teacher_velocity_reset/timestep_search/cloth_coarse/bend500_accuracy.md)가 소유한다. R1 XeLaTeX 재빌드 성공, PDF와 전달 bundle의 R1 TeX/PDF를 갱신·검증했다. R0·master·sketch·Gate·기본 적분법은 변경하지 않았다.
