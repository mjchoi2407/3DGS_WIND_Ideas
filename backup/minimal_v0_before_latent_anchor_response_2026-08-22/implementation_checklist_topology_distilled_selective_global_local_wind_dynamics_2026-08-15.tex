\section{목적, 범위와 즉시 중단 조건}

목표는 평면 rest strip/rectangular flag에서 visually plausible하고 stable한 wind animation을 만들면서
strong Global rank와 same-anchor sparse solver 밖의 quality--latency Pareto 점을 찾는 것이다.
Engineering-grade shell accuracy는 완료 조건이 아니다.
정량 core scope는 고정된 계약 \code{flat\_rest\_v0}이며,
shallow/pre-curved rest surface는 Gate 이후의 non-blocking extension으로 남겨 둔다.

\subsection{V0 core}

\begin{enumerate}
  \item static GS에서 \code{flat\_rest\_v0} sparse oriented anchor scaffold와
  area/mass를 만든다.
  \item user material/hard attachment로 one-local-step fixed-Hessian PD-style
  stretch--bending backend를 고정한다.
  \item 모든 anchor에서 current-surface quasi-steady aero를 한 번 계산한다.
  \item future-error estimator가 아닌 deterministic dwell-reserved capacity-\(K_A\)
  compliance proxy selector와
  Active/Decay state를 사용한다.
  \item \([\Phi,\Psi_{\mathcal S}]\)에 direct projection하고 cross block을 포함해 한 번 푼다.
  \item anchor deformation을 Gaussian mean/covariance로 affine transport한다.
\end{enumerate}

\begin{tcolorbox}[colback=StopLight,colframe=StopRed,title=V0 forbidden work,fonttitle=\bfseries]
Gate A/B/C 전에는 H/F/G, patch-force lifting/KKT/Schur, support reaction routing,
same-frame corrector, calibrated confidence network, Teacher-FSI, nonlinear shell extension과
learned hysteresis를 구현하지 않는다. Incremental factorization은 direct factor/solve가
synchronized profiler에서 실제 병목으로 확인되기 전에는 구현하지 않는다.
이론적 edge case만으로 새 core module을 추가하지 않는다.
\end{tcolorbox}

\subsection{즉시 중단 또는 축소}

\begin{itemize}
  \item Oracle scaffold에서도 stable backend를 만들지 못하면 topology training을 시작하지 않는다.
  \item Privileged-teacher-ranked Local이 strong Global-rank보다 낫지 않으면 selector와 MC2를 중단한다.
  \item Predicted scaffold가 Gate A를 못 통과하면 MC1을 user-hinted/explicit scaffold로 축소한다.
  \item Same-anchor baseline 대비 실제 Pareto 이득이 없으면 speed headline을 철회한다.
\end{itemize}

\subsection{API와 manifest}

필수 API는 다음 이름과 책임을 가진다. 내부 signature는 구현 언어에 맞춰도 되지만
입출력 type과 owner는 바꾸지 않는다.

\begin{itemize}
  \item \code{build\_anchor\_scaffold(setup) -> AnchorScaffold}
  \item \code{build\_structural\_package(scaffold, setup) -> StructuralPackage}
  \item \code{build\_reduced\_package(scaffold, structural) -> ReducedPackage}
  \item \code{reconstruct\_surface(state, packages) -> SurfaceState}
  \item \code{evaluate\_full\_anchor\_aero(surface, wind) -> AnchorForceField}
  \item \code{select\_local\_units(force, state, reduced) -> LocalSelection}
  \item \code{solve\_coupled\_step(force, selection, state, packages) -> RuntimeState}
  \item \code{transport\_gaussians(state, scaffold) -> GaussianFrame}
\end{itemize}

모든 run은 \code{minimal\_v0\_manifest.json}에 source commit, package hashes와
asset/GS seed를 기록한다. \code{unit\_mode}와 해당 branch payload,
\code{core\_scope=flat\_rest\_v0}, structural backend 및 constraint-map version,
material/aero preset, \(r_g,K_A,K_D,\Delta t\)를 기록한다.
\code{atomic\_group\_map}, \code{group\_member\_order},
\code{group\_column\_ranges}, \code{stable\_unit\_order}와 각 atomic group의
versioned merge/prune 뒤 exact serialized retained \(\Psi_{\mathcal G}\)는
reduced-package hash가 소유한다. Run manifest/hash는 \(K_A\)와 이 exact reduced-package
identity를 함께 기록한다. 둘 중 하나라도 다르면 동일 method replay로 취급하지 않고 fail-fast한다.
이는 member basis의 unconditional concatenation이나 하나의 전역 concatenated-array 저장을
강제하지 않는다.

Bending projection signature는 \code{bend\_projection\_version}과
\code{corotated\_tangent\_plane\_v2}의 pair로 기록한다.
Setup frame signature도 \code{tangent\_gauge\_version}과
\code{attachment\_line\_v1}의 pair로 기록한다.
Canonical Minimal V0의 in-plane orientation policy는 learned \(\Delta\theta_i=0\)이며
별도 orientation output을 호출하지 않는다.
Gauge의 attachment reference, degeneracy threshold/reject rule, accepted unoriented axis와
unit normalization, line-projector idempotence/sign--raw-scale replay 결과를
scaffold/structural package hash에 포함한다.

V0-R1 artifact에는 다음 version group과 object-grouped split/data hash,
모든 threshold/cap을 기록한다.
\begin{itemize}
  \item \code{anchor\_sampler\_version}, \code{candidate\_graph\_version},
  \code{feature\_norm\_version}
  \item \code{topology\_architecture\_version}, \code{topology\_label\_version},
  \code{topology\_loss\_version}
  \item \code{topology\_decoder\_version}, \code{topology\_split\_version}
\end{itemize}
\code{topology\_architecture\_version}과 \(\nu_{\rm arch}\) hash는
shared scalar area head의 \(h_i\)-only input contract, \(|V|\times1\) output shape,
width/depth/activation과 output field ID를 포함한다. Area logit 앞에 global pooling이나
새 message-passing stage를 추가하지 않는다.
Object-grouped split/data hash와 test seal을 먼저 고정한다.
각 training run 전 \code{PRE\_TRAIN}에는 anchor/candidate/feature/architecture/label/loss field를
concrete non-placeholder로 만들고 decoder schema와 threshold/cap candidate space,
training seed, training data/label hash와 train-only statistic을 포함한 run hash를 닫는다.
이때 dev 결과로 정할 최종 numerical threshold/cap과 \(\nu_{\rm decode}\)는 요구하지 않는다.
Decoder threshold/cap, selected model weight와 최종 canonical config는 train/dev 결과로만 선택한다.
Test payload를 처음 열기 전 \code{PRE\_TEST}에는 dev-selected final \(\nu_{\rm decode}\),
선택한 model weight 및 source/label/data/config/decoder/split의 immutable full hash를 동결한다.
Test result 확인 뒤 field를 바꾸면 새 preregistered run으로 취급한다.
각 단계의 required field가 unset이면 해당 V0-R1 entry point는 fail-fast하지만,
이 상태가 explicit Oracle scaffold 기반 V0-01--04 또는 privileged-teacher-ranked Gate B와
preliminary/final Gate C를 막지는 않는다.
이는 이미 선언한 MC1의 offline artifact 계약이며 새 runtime stage나 learned output이 아니다.

Global basis signature는 \code{basis\_type=generalized\_eigen\_v1}로 기록한다.

\code{tangent\_fit\_version} 값은 \code{tangent\_fit\_v1}로 기록한다.
Shared \(J/G\) relative--absolute numerical-rank threshold,
unit-typed \(\lambda_{G,\mathrm{abs}}^{(\mathsf u)}\), inverse-before-check fixture를 package hash에 포함한다.

Canonical V0의 binding/run manifest는 별도 실행 field
\code{appearance\_mode=degree0\_v0}를 기록한다. 이는 위 method signature를
늘리거나 method authority를 바꾸는 field가 아니다.

Active/Decay 수치 parameter도 기록한다.
\[
\begin{gathered}
  K_A,K_D,N_{\rm dwell},N_{\rm fade},N_{\rm hold},\\
  \tau_E,\tau_x,\tau_v,\tau_{\rm pop}.
\end{gathered}
\]
첫 줄은 1 이상인 integer이고, 둘째 줄은 모두 finite positive scalar인지
manifest validation에서 확인한다. Strict \(<\) release predicate는 유지하며 0 tolerance를 허용하지 않는다.
Operating-envelope field
\[
  W_{\max},\quad \dot W_{\max},\quad G_{W,\max},\quad f_{\max},\quad
  \mathcal B_{\rm area/affine/cov}
\]
와 fixed internal substep \(N_{\rm sub}=1\), hardware, precision, command,
deferred-module flags와 이미 동결한 force/area/affine/covariance clamp-rate cap도 기록한다.
선택한 unit branch에 맞는 typed invariant \(f_{\max}>0\)를 manifest validation에서 확인한다.
Deferred flag는 모두 false여야 canonical V0 run이다.
S4/Gate manifest는 실행 전에 raw-force가 finite여야 하는 required anchor--frame index set
\(\mathcal I_f\)를 등록한다. 이는 실행 뒤 관측한 finite sample subset이 아니다.
\[
  N_{\rm force}^{\rm req}=|\mathcal I_f|,\qquad
  N_{\rm force}^{\rm clamp}
  =\sum_{(i,t)\in\mathcal I_f}
  \mathbf 1[\,f_{\rm raw,i}^t\text{ finite}\ \land\
  \|f_{\rm raw,i}^t\|_2>f_{\max}\,],\qquad
  r_{f,\mathrm{clip}}=\frac{N_{\rm force}^{\rm clamp}}{N_{\rm force}^{\rm req}}.
\]
Non-finite raw-force event는 별도 method failure이며 \(\mathcal I_f\) 분모에서 제거하거나
성공 표본으로 숨기지 않는다. \(r_{f,\mathrm{clip}}\)에는 이미 동결한 generic force
clamp-rate cap만 적용하고 별도 cap, threshold 또는 gate를 만들지 않는다.
Scaffold/structural/reduced/binding package hash와 더불어 constraint-map,
generalized-eigen basis, tangent-fit contract의 각 replay hash를 저장한다.
SI/nd conversion table의 모든 값, bound와 typed epsilon은 선택한 branch payload와
round-trip fixture hash에 포함한다. Evaluation epsilon은 finite positive이고
\[
\begin{aligned}
  \operatorname{unit}(\varepsilon_v)&=ML^2/T^2,&
  \widehat\varepsilon_v&=\varepsilon_vT_0^2/(M_0L_0^2),\\
  \operatorname{unit}(\varepsilon_x)&=L^2,&
  \widehat\varepsilon_x&=\varepsilon_x/L_0^2
\end{aligned}
\]
로 변환한다. \(\varepsilon_v,\varepsilon_x\), unit branch, 변환 결과와 inverse
round-trip 결과는 \code{evaluation\_hash}가 소유한다.
각 Gate manifest는 실행 전에 canonical package/sequence attempt 목록과 다음 집계량을 고정한다.
\[
\begin{gathered}
N_{\mathrm{pkg}}^{\mathrm{attempt}},\quad N_{\mathrm{pkg}}^{\mathrm{accepted}},\\
N_{\mathrm{seq}}^{\mathrm{attempt}},\quad N_{\mathrm{seq}}^{\mathrm{successful}}.
\end{gathered}
\]
집계 규칙과
development split에서 동결한 \(\tau_{\mathrm{fail},A},\tau_{\mathrm{fail},C}\)를 저장한다.
Binding/run manifest에는 relative singular-value numerical-rank threshold \(\tau_K\),
affine-safe SVD의 \(\sigma_{F,\mathrm{rank}},\sigma_{F,\min},\sigma_{F,\max}\), reflection-invalid rule,
proper-rigid fallback ID와 renderer fallback-rate cap \(\tau_{\mathrm{rigid}}\)을 저장한다.
Affine singular-value clamp, reflection invalidation과 rigid-fallback event rate도 각각 trace/hash에 남긴다.
Gate evidence manifest에는 reference refinement pair/common evaluation grid,
fixed common evaluation mass, reference-convergence threshold, sequence metric aggregation,
object/package cluster ID와 \(N_{\rm obj,min}\),
paired-CI procedure와 practical Pareto margin을 결과 확인 전에 저장한다.
PSD evaluation에는 기존 typed \((L_0,T_0)\),
\(\widehat f_{\rm PSD}=f_{\rm PSD}T_0\),
\(\widehat P(\widehat f_{\rm PSD})=P(f_{\rm PSD})T_0/L_0^2\),
\(\widehat\varepsilon_P=\varepsilon_PT_0/L_0^2\), window와 dimensionless bin을 저장한다.
L1/RMS log-PSD를 모두 보고하되 development split에서 정확히 하나를 primary로 동결하고
다른 하나를 mandatory secondary로 저장한다. SI direct ratio 계산에 새 독립 PSD time scale을 만들지 않는다.

\section{여덟 개 hard gate}

\begin{itemize}

\section{Gate A/B/C 실행 계약}

\subsection{공통 평가 분모와 method failure}

각 Gate는 canonical sketch의
\code{eq:minimal-attempt-success-contract}에 따라 test execution 전에
in-envelope package/sequence attempt 목록을 manifest에 고정한다.
\(R_{\mathrm{accept}}\)는 accepted package 수를 registered package attempt 수로,
\(R_{\mathrm{success}}\)는 successful sequence 수를 registered sequence attempt 수로 나눈다.
Package rejection으로 실행할 수 없어진 registered sequence도 sequence attempt 분모에 남긴다.
사전 판정한 \(W\notin\mathcal E_{\mathrm{op}}\) input은 canonical 분모 밖 OOD로 분리할 수 있지만,
\(W\in\mathcal E_{\mathrm{op}}\)에서 발생한 package reject, rank collapse, divergence,
invalid covariance, rigid-fallback failure 또는 fallback-rate cap 초과는 method failure다.

성공 표본 위 conditional quality와 함께 accept/success/method-failure rate를 항상 보고한다.
Conditional quality가 좋아도 \(1-R_{\mathrm{accept}}>\tau_{\mathrm{fail},A}\)이면 Gate A,
\(1-R_{\mathrm{success}}>\tau_{\mathrm{fail},C}\)이면 final deployable Gate C를 통과하지 못한다.
Capped-error 집계는 보조 diagnostic으로 함께 보고할 수 있으나 유일한 합격 지표로 강제하지 않는다.

Accuracy reference의 spatial/time refinement pair, common evaluation anchor/grid와
\(\tau_{\rm ref}\)는 test 전에 고정한다. Reference convergence 실패는
\code{reference\_construction\_failure}이며 method failure와 별도 열로 보고하고
method denominator/status를 바꾸지 않는다.
Frame은 독립 표본으로 쓰지 않고 sequence metric 안에서만 집계한다.
Method--baseline sequence 차이는 source object와 그 nested independent package cluster를 보존한
paired 95\% CI와
함께 보고한다.

\subsection{Gate B --- complementary Local necessity}

동일 synchronized p95 dynamics latency에서 strong Global rank sweep과
Global+privileged-teacher-ranked Local을 먼저 비교한다. Coordinate/rank match는 diagnostic일 뿐
same-p95 공정성을 대체하지 않는다.

\must{Primary:} object-scale-normalized sequence RMS velocity error 대 p95.
\must{Required secondary:} tip trajectory, dimensionless L1/RMS log-PSD, traveling-gust response,
activation pop. Privileged-teacher-ranked Local이 반복적인 non-dominated point를 못 만들면 MC2를 중단한다.

Privileged teacher selector는 sketch의 고정 atomic units와 동일 \(K_A,K_D\), 동일 coupled solver를 사용하고,
development에서 동결한 future-window teacher velocity/PSD error 감소량으로만 rank한다.
Label search 비용은 제외하되 선택 뒤 actual execution cost는 p95에 포함한다.
이는 scope-control용 privileged diagnostic이며 exact best-subset oracle 또는 formal upper bound가 아니다.

Offline scoring protocol은 \code{teacher\_counterfactual\_v1}로 고정한다.
각 scoring 시점의 full serialized \code{RuntimeState}를 candidate별로 deep-copy하며,
Global/Local coordinate와 velocity, Active/Decay membership, dwell age, fade/release 상태와
모든 timer/counter를 빠짐없이 복제한다. Scoring 시작 시 minimum-dwell 때문에 반드시 유지해야 하는
Active unit 집합을 \(\mathcal A_{\rm mand}\)로 snapshot한다. 동일 initial copy에서
base desired-set request를 \(\mathcal A_{\rm mand}\)로, candidate \(r\)의 isolated request를
\(\mathcal A_{\rm mand}\cup\{r\}\)로 두고 \(r\)을 highest optional priority로 고정해 비교한다.
두 branch는 동일 future horizon, wind/reference, solver, precision, seed와 동결 config를 사용하고,
각각의 desired-set request를 horizon 동안 고정한 채 기존 admission/fade/release policy를 그대로 실행한다.
Full-capacity를 포함한 실제 admission/replacement/delay는 기존 capacity-\(K_A\) policy가 horizon 전체에서
결정하며 candidate를 slot에 강제 삽입하거나 별도 admission rule을 만들지 않는다.
중간 state reset, recursive re-ranking과 subset search는 금지한다.
Candidate가 첫 frame에 admit되지 않았다는 이유만으로 score를 0으로 두지 않으며,
두 전체 rollout의 state/metric trace가 동일할 때만 0으로 둔다.
Gate-B manifest와 selector report는 \code{teacher\_counterfactual\_v1}, \(H\), teacher metric,
tie-break, serialized initial-state hash와 wind/reference/config hash를 소유한다.

그 뒤 deterministic compliance selector를 동일 \(K_A\)와 actual p95에서 privileged-teacher-ranked,
random, curvature와 비교한다. Privileged-teacher-ranked gap이 크다는 이유만으로 learned gate를 추가하지 않는다.
Compliance score는 isolated external-load proxy이며 future-error estimator가 아니다.
Selector report는 privileged-teacher-ranked gap과 activation delay를 함께 기록한다.
Gate B pass에는 수치상 strict non-domination뿐 아니라 development에서 동결한 practical
error/latency margin과 object/package-clustered paired CI를 요구한다.

\subsection{Gate C --- deployable gain}

\must{Compare:} 동일 constraint/timestep의 optimized full-coordinate same-anchor PD backend,
Global rank sweep, always-on Local,
privileged-teacher-ranked Local, deterministic Local. MPM-only speed comparison은 합격 근거가 아니다.

\must{Pass evidence:} 다음 중 하나에서 same-anchor Pareto envelope 밖의 명확한 점을 요구한다.

\begin{itemize}
  \item matched-quality dynamics speed,
  \item same-p95 quality,
  \item matched-quality multi-object relative throughput.
\end{itemize}

통과하지 못하면 speed/actual-skip headline을 철회한다.
\(N_G\)-scaling은 SYS 보조 증거이며 단독 Gate-C 합격 근거가 아니다.
Gate C의 deterministic point도 Gate B와 같은 preregistered Pareto margin, clustered paired CI와
\(R_{\rm success}\) cap을 함께 통과해야 한다.

Gate A/B/C 결과가 살아남은 뒤의 paper-evidence 단계에서만, 공개 구현과
domain comparability를 확인한 direct wind-responsive 3DGS baseline을 정확히 한 개 선택한다.

여러 3DGS adaptation을 Minimal V0의 Gate, P0 또는 초기 kill test에 동시에 추가하지 않는다.
