\begin{tcolorbox}[breakable,colback=white,colframe=black!35,title=Stretch weight,fonttitle=\bfseries]
\textbf{Source:} relation weight 정의부
\[
\begin{aligned}
[w_e^{\mathrm{str}}]
&=
\left[
\kappa_{\mathrm{str}}
\frac{a_e^{\mathrm{own}}}{(\ell_e^0)^2+\varepsilon_\ell^2}
\right]\\
&=
\frac{M}{T^2}\frac{L^2}{L^2}
=
\frac{M}{T^2}
=
\frac{\mathrm N}{\mathrm m}.
\end{aligned}
\]
Position residual quadratic weight와 일치한다. \pass
\end{tcolorbox}

\begin{tcolorbox}[breakable,colback=white,colframe=black!35,title=Bending weight,fonttitle=\bfseries]

\[
\begin{aligned}
[w_{ia}^{\mathrm{bend}}]
&=
\left[
\kappa_{\mathrm{bend}}

\right]\\

\frac{ML^2}{T^2}\frac{L^2}{L^4}

\end{aligned}
\]
Stretch channel과 동일한 residual-weight 차원이다. \pass
\end{tcolorbox}

\begin{tcolorbox}[breakable,colback=white,colframe=black!35,title=Rest-offset structural load,fonttitle=\bfseries]
\textbf{Source:} \src{eq:minimal-structural-backend}

$x=x^0+By$를 사용하면
\[
\begin{aligned}
B^\top(Kx-h)
&=B^\top KBy+B^\top(Kx^0-h)\\
&=B^\top KBy-B^\top(h-Kx^0).
\end{aligned}
\]
따라서 $\bar h=h-Kx^0$를 reduced load에 사용하는 것이 맞다. \pass
\end{tcolorbox}

\begin{tcolorbox}[breakable,colback=white,colframe=black!35,title=Implicit midpoint,fonttitle=\bfseries]
\textbf{Source:} \src{eq:minimal-coupled-step}

$\Delta y=y^t-y^{t-1}$,
$\dot y^t=2\Delta y/\Delta t-\dot y^{t-1}$이면
\[
\dot y^{t-1/2}=\frac{\Delta y}{\Delta t},
\qquad
\ddot y^{t-1/2}
=
\frac{2\Delta y}{\Delta t^2}
-
\frac{2\dot y^{t-1}}{\Delta t}.
\]
$M\ddot y+C\dot y+Ky=r$를 midpoint에서 평가하고 2배하면
\[
\left(
\frac{4}{\Delta t^2}M+
\frac{2}{\Delta t}C+K
\right)\Delta y
=
2r-2Ky^{t-1}+\frac{4}{\Delta t}M\dot y^{t-1}
\]
가 되어 source와 일치한다. \pass
\end{tcolorbox}

\begin{tcolorbox}[breakable,colback=white,colframe=black!35,title=Quasi-steady aero,fonttitle=\bfseries]
\textbf{Source:} \src{eq:minimal-aero}

\[
[\rho_{\mathrm{air}}av^2]
=
\frac{M}{L^3}L^2\frac{L^2}{T^2}
=
\frac{ML}{T^2}
\]
로 force 차원이다. $n\mapsto -n$이면 $v_n\mapsto -v_n$이므로

|{-v_n}|(-v_n)(-n)=|v_n|v_nn
\]
이고 $v_nn$도 불변이어서 tangential component 역시 불변이다. \pass
\end{tcolorbox}

\begin{tcolorbox}[breakable,colback=white,colframe=black!35,title=Selector proxy,fonttitle=\bfseries]

그러나 release는 strict inequality를 사용한다.

\paragraph{구체적 반례 또는 실패 경로.}

Traveling gust가 patch를 순차적으로 이동시키는 동안 $K_D$개의 Decay slot이 찬 뒤 release가 발생하지 않으면,
outgoing Active를 유지해야 하므로 새 desired candidate의 activation delay가 무기한 누적될 수 있다.

\paragraph{무효화될 수 있는 core claim.}
Fixed-cardinality selective execution, switching continuity, deterministic selector의 deployability,
actual p95에서의 Local skip 이득이 영향을 받는다.

\paragraph{기존 fail-fast/limitation으로 부족한 이유.}
반복 실패 시 MC2를 철회하는 S5 조치는 잘못 허용된 config domain 때문에 정상 state machine을 실패시킨 뒤의
사후 축소다. 이 문제는 config validation에서 제거할 수 있으므로 failure evidence로 소비할 이유가 없다.

\paragraph{최소 수정안.}
수치적 release tolerance라는 현재 의미를 유지하며 다음 positivity를 hard validation으로 둔다.
\begin{equation}
  \tau_E>0,\qquad
  \tau_x>0,\qquad
  \tau_v>0,\qquad
  \tau_{\mathrm{pop}}>0.
\end{equation}

전체 config validator는 최소한 다음 conjunction을 검사한다.
\begin{equation}
\begin{aligned}
\operatorname{ValidStateConfig}
:=&\ (K_A\geq1)\land(K_D\geq1)
\land(N_{\mathrm{dwell}}\geq1)
\land(N_{\mathrm{fade}}\geq1)
\land(N_{\mathrm{hold}}\geq1)\\
&\land\bigwedge_{\tau\in\{\tau_E,\tau_x,\tau_v,\tau_{\mathrm{pop}}\}}
\left(\operatorname{finite}(\tau)\land\tau>0\right).
